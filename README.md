# Villa Leona · Jardín de Eventos

Página de presentación de precios y amenidades para Villa Leona, operado por Primavera Events Group.

## Contenido

- `index.html` — página de una sola vista (portada en video, amenidades, paquete todo incluido, menú, equipo de servicio, DJ, cortesías y contacto).

## Paquete vigente

- **Todo incluido:** $1,250 MXN/persona (menú 3 tiempos) · $1,299 MXN/persona (menú 4 tiempos)
- Incluye 8 horas de servicio + 1 hora de regalo para la ceremonia
- Hora extra adicional (uso de salón): $12,000 MXN
- Área consagrada (ceremonia religiosa): +$100

## Publicar con GitHub Pages

1. Ve a **Settings → Pages** en este repositorio.
2. En "Build and deployment", selecciona la rama `main` y la carpeta `/ (root)`.
3. Guarda; la página quedará disponible en `https://5410m0n0c001.github.io/Villa-leona-/`.
